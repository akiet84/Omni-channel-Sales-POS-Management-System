# Matt Pocock Skills for Antigravity (Project-level)

Collection of 27 engineering and productivity skills by Matt Pocock, packaged natively for Google Antigravity inside this project.

## Included Skills

### Engineering
- **ask-matt**: Find the right skill or workflow.
- **code-review**: Thorough, structured code review with findings ranked by severity.
- **codebase-design**: Design vocabulary: seams, adapters, depth, leverage, locality.
- **diagnosing-bugs**: Disciplined diagnosis loop for hard bugs and regressions.
- **domain-modeling**: Model domain language, ubiquitous vocabulary, and ADRs.
- **grill-with-docs**: Interview user to shape documentation.
- **implement**: Systematic implementation process.
- **implement-spec**: Take a spec document and execute it step-by-step.
- **improve-codebase-architecture**: Structural analysis and architectural refactoring.
- **pr**: Prepare clean pull requests with meaningful descriptions.
- **prototype**: Rapid UI and logic prototyping.
- **research**: Targeted research before implementation.
- **retro**: Retrospective review after shipping.
- **setup-matt-pocock-skills**: Initialize issue tracker, triage labels, and domain docs.
- **tdd**: Red-green-refactor loop at agreed seams.
- **to-spec**: Turn user ideas and design discussions into actionable specs.
- **to-tickets**: Break specs or features down into issue tracker tickets.
- **triage**: Systematically triage inbound issues.
- **wayfinder**: Orient inside an unfamiliar codebase.
- **wizard**: Multi-step terminal wizard harness.

### Productivity
- **grill-me**: Shortcut to run relentless design interview.
- **grilling**: Relentless interview to explore design decisions and assumptions.
- **handoff**: Session summary and handoff notes for next session.
- **teach**: Socratic teaching framework.
- **to-questionnaire**: Formulate targeted questions for stakeholder alignment.
- **wait-what**: Step back and double-check questionable decisions or odd code.
- **writing-for-agents**: Guide for writing instructions, skills, and rules consumed by AI agents.
